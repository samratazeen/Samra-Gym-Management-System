SAMRA - GYM MEMBERSHIP MANAGEMENT SYSTEM
Designed & Developed by Samra

1. Extract this ZIP into a new folder, for example Desktop\Samra_Gym_Management.
2. Open the extracted folder in VS Code.
3. Ensure MySQL Server is running. Your database gym_management and its five tables were already created in Workbench.
4. Open server.js and change password "root23" to your actual MySQL root password if it is different.
5. Open VS Code Terminal in this project folder and run: npm install
6. Run: npm start
7. Open: http://localhost:3000

If you have not created the database/tables, open database.sql in MySQL Workbench and execute it.
Do not double-click index.html. Use the localhost address after starting the server.
